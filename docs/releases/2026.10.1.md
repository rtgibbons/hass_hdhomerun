# 2026.10.1

[Documentation](https://github.com/rtgibbons/hass_hdhomerun/blob/2026.10.1/docs/README.md)

This is the first stable custom-install snapshot
release of [rtgibbons/hass_hdhomerun](https://github.com/rtgibbons/hass_hdhomerun),
the maintained fork of
[uvjim/hass_hdhomerun](https://github.com/uvjim/hass_hdhomerun). The original
integration was developed by uvjim and its contributors; fork attribution does
not imply upstream endorsement.

## Version and requirements

- Version: **2026.10.1**, following the latest
  verified upstream release, **2026.9.1** (verified October 25, 2026).
- Fork versions follow `year.month.revision`, with releases tracked separately
  from upstream in HACS. Matching upstream version numbers do not conflict.
- Requires **Home Assistant 2026.1.0 or later** and a reachable HDHomeRun receiver.
- The community dashboard picker requires HA 2026.5 or later; earlier supported
  versions can use the [blank-dashboard setup](https://github.com/rtgibbons/hass_hdhomerun/blob/2026.10.1/docs/dashboard.md#add-the-dashboard).

## Highlights

- A bundled, optional managed dashboard with compact tuner cards, responsive
  24/36/48-hour capacity history, reception alerts, and maintenance views.
- Optional cached XMLTV guide and matching M3U playlist proxy, with guide-health
  diagnostics. The proxy is off by default; treat player URLs as secrets.
- US and British English display text, respecting Home Assistant language,
  clock, and sensor-unit preferences.
- Receiver/tuner monitoring and controls, plus diagnostic redaction work and
  expanded setup, dashboard, guide, and troubleshooting documentation.

Features depend on receiver capabilities and discovery method. See the
[entity reference](https://github.com/rtgibbons/hass_hdhomerun/blob/2026.10.1/docs/entities.md)
and [guide proxy documentation](https://github.com/rtgibbons/hass_hdhomerun/blob/2026.10.1/docs/epg.md).

## Install or upgrade

Add `https://github.com/rtgibbons/hass_hdhomerun` to HACS as a custom
**Integration** repository and download **2026.10.1**. This fork is not in the
default HACS list. `develop` is opt-in ongoing development, not the stable channel.

**Back up Home Assistant before switching or upgrading.** This fork and upstream
both use the `hdhomerun` integration domain and cannot be installed alongside
one another. Keep only one source managing that integration directory. Follow
the [source-switch and rollback procedure](https://github.com/rtgibbons/hass_hdhomerun/blob/2026.10.1/docs/installation.md#switch-from-upstream-or-roll-back),
including recording the old version and preserving user-owned dashboard YAML.

HACS uses the attached `hdhomerun.zip` (`zip_release: true`). The same ZIP
supports manual installation and contains integration files at its root;
extract them into `<config>/custom_components/hdhomerun/`, not directly into
`custom_components/`. See [manual installation](https://github.com/rtgibbons/hass_hdhomerun/blob/2026.10.1/docs/installation.md#manual-installation).

After installation, restart Home Assistant and hard refresh browsers. Verify
existing receivers, entities, options, and dashboards before relying on them.
The shared domain is intended to preserve identity but does not prove every
upgrade or downgrade is configuration-compatible. Add the managed dashboard
explicitly; no sidebar entry is created automatically. A dashboard you have
taken control of remains user-owned and does not receive managed layout updates.

## Rollback

Reinstall the previously recorded source version or published release, restart
Home Assistant, and hard refresh browsers. Replace the entire integration
directory rather than mixing files across versions. If stored configuration
or dashboard state is incompatible, restore the full pre-upgrade backup.
Returning to upstream removes fork-only functionality: restore or remove
dependent dashboards and guide/player settings as needed. Do not try to keep
both integrations installed as a rollback strategy.
