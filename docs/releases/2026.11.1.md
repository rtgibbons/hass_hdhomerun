# 2026.11.1

[Documentation](https://github.com/rtgibbons/hass_hdhomerun/blob/2026.11.1/docs/README.md)

This maintenance release of
[rtgibbons/hass_hdhomerun](https://github.com/rtgibbons/hass_hdhomerun)
follows the published **2026.10.1** custom-install release. It retains the fork's
features while incorporating upstream corrections and November Home Assistant
test compatibility. The original integration was developed by
[uvjim](https://github.com/uvjim/hass_hdhomerun) and contributors;
fork attribution does not imply upstream endorsement.

## Changes and retained features

- Incorporates the upstream sensor import correction from
  [PR #128](https://github.com/uvjim/hass_hdhomerun/pull/128), fixing sensor
  platform loading on Home Assistant 2026.11.
- Updates test compatibility for Home Assistant 2026.11, with a CI matrix of
  Python 3.13 / HA 2026.2.3 and Python 3.14 / HA 2026.11.0. The November pin is
  the stable release, not a beta. This matrix is not a claim of live receiver
  validation or exhaustive coverage of every supported HA version.
- Inherits upstream's new Apache-2.0
  [LICENSE](https://github.com/rtgibbons/hass_hdhomerun/blob/2026.11.1/LICENSE).
  Preserve the license and upstream attribution. Its source is upstream
  [commit c921b78](https://github.com/uvjim/hass_hdhomerun/commit/c921b78d147bb8ddace0f0754be4c44d89a5a8b3);
  this does not establish blanket historical permissions or settle all
  vendored-code provenance questions. See the
  [licensing notes](https://github.com/rtgibbons/hass_hdhomerun/blob/2026.11.1/docs/releasing.md#licensing-status).

The fork features from 2026.10.1 remain unchanged: the optional managed dashboard
with compact tuner cards, capacity history, reception alerts, and maintenance
views; optional cached XMLTV/M3U proxy and guide-health diagnostics; US and
British English display text; and receiver/tuner monitoring and controls.
The guide proxy remains off by default; treat guide/player URLs as secrets.
Features depend on receiver capabilities and discovery method. See the
[entity reference](https://github.com/rtgibbons/hass_hdhomerun/blob/2026.11.1/docs/entities.md)
and [guide proxy documentation](https://github.com/rtgibbons/hass_hdhomerun/blob/2026.11.1/docs/epg.md).

## Requirements and installation channel

- Requires **Home Assistant 2026.1.0 or later** and a reachable HDHomeRun receiver.
- The community dashboard picker requires **HA 2026.5 or later**; earlier
  supported versions can use the
  [blank-dashboard setup](https://github.com/rtgibbons/hass_hdhomerun/blob/2026.11.1/docs/dashboard.md#add-the-dashboard).
- This remains a custom-install release, not a default HACS listing or a claim
  of eligibility. The HACS eligibility workflow remains `disabled_manually`
  at the owner's explicit request. The new license does not change that status.

## Install or update

**Back up Home Assistant first.** Record the installed repository and version,
integration options, and dashboard settings; save user-owned dashboard YAML.
This fork and upstream both use the `hdhomerun` domain and cannot be installed
side-by-side. Keep only one source managing the integration directory.

Add `https://github.com/rtgibbons/hass_hdhomerun` to HACS as a custom
**Integration** repository and select **2026.11.1**. Existing fork users can
select this version when downloading an update. `develop` is opt-in ongoing
development, not the stable release channel.

HACS uses the attached `hdhomerun.zip` (`zip_release: true`). For manual installs,
download the same asset from the
[2026.11.1 release](https://github.com/rtgibbons/hass_hdhomerun/releases/tag/2026.11.1).
Its runtime files are at the ZIP root: extract them into
`<config>/custom_components/hdhomerun/`, not directly into `custom_components/`.
Replace the complete integration directory rather than mixing versions.
See the [installation and source-switch procedure](https://github.com/rtgibbons/hass_hdhomerun/blob/2026.11.1/docs/installation.md).

Restart Home Assistant and hard refresh browsers after installation. Check
existing receivers, entities, options, and dashboards before relying on them.
Add the managed dashboard explicitly; no sidebar entry is created automatically.
A dashboard you have taken control of remains user-owned and does not receive
managed layout updates. The shared domain is intended to preserve identity,
not a guarantee of configuration compatibility across every upgrade or downgrade.

## Rollback

Reinstall the previously recorded source version or the previous published fork
release, [2026.10.1](https://github.com/rtgibbons/hass_hdhomerun/releases/tag/2026.10.1).
Replace the entire integration directory, restart Home Assistant, and hard
refresh browsers. If stored configuration or dashboard state is incompatible,
restore the full pre-upgrade backup. Returning to upstream removes fork-only
features: restore or remove dependent dashboards and guide/player settings as
needed. Do not keep both integrations installed as a rollback strategy.
